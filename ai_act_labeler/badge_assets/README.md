Place the official EU "AI" badge PNG file here to make the tool use it automatically.

Filename: eu_badge.png
Preferred format: PNG with alpha channel (RGBA). Square 256x256 or 512x512 recommended.

Usage:
- Put the provided `eu_badge.png` into this directory:

  ai_act_labeler/badge_assets/eu_badge.png

- The pipeline will automatically prefer this badge over the generated default.
- Alternatively, pass a custom badge at runtime with `--badge /path/to/badge.png`.
